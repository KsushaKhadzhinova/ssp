# ЛР2. Управление памятью в C# и анализ утечек

- `Lab2/Program.cs` – все задания в одном файле, запуск через меню.
- `report/Отчет_ЛР2.docx`, `report/Отчет_ЛР2.pdf` – отчет по СТП БГУИР 01-2024.

```
dotnet run -c Release --project Lab2
```
