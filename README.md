# ССП – лабораторные работы

Лабораторные работы по дисциплине «Современные системы программирования» (C#, .NET). Каждая работа находится в отдельной ветке: исходный код в папке `LabN`, отчёт в папке `report`.

| Ветка | Лабораторная работа |
|---|---|
| [lab-1](../../tree/lab-1) | №1. Платформа .NET: анализ IL-кода и JIT-компиляции |
| [lab-2](../../tree/lab-2) | №2. Управление памятью в C# и анализ утечек |
| [lab-3](../../tree/lab-3) | №3. Рефлексия в C#: механизм System.Type и позднее связывание |
| [lab-4](../../tree/lab-4) | №4. Поиск утечек памяти и профилирование производительности |

## Запуск

Нужен .NET SDK 8.0 или новее. В папке проекта нужной ветки:

```bash
dotnet run
```

Особые режимы запуска:

- `Lab1`: `dotnet run -c Release -- bench` (BenchmarkDotNet).
- `Lab2`: `dotnet run -c Release -- task7` (задание 7), `-- snapshots` (этапы для снимков памяти).
- `Lab4`: `dotnet run -c Release -- buggy` (задание 4), `-- calltree` (профилирование).
