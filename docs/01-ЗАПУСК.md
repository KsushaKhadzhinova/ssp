# ССП, лабораторная работа 3. Как запустить

Тема: **Рефлексия в C#: механизм `System.Type` и позднее связывание**. Код в папке `Lab3`.

## Что установить

| Что | Зачем | Проверка |
|---|---|---|
| **.NET SDK 10** | сборка и запуск | `dotnet --version` |
| VS Code (C# Dev Kit) или Visual Studio 2022 | показывать код | |

Интернет нужен только для первой установки SDK: у проекта нет внешних пакетов.

## Запуск

```bash
git clone https://github.com/KsushaKhadzhinova/ssp.git
cd ssp
git checkout lab-3
cd Lab3
dotnet run
```

Программа без аргументов выполняет **всё по порядку**: три примера из методички, затем задания 1–7. Вывод длинный (около 250 строк), поэтому удобно запускать в терминале с прокруткой или перенаправить в файл: `dotnet run > out.txt`.

## Файл plugins.config

Это текстовый файл рядом с программой (`bin/.../plugins.config`), в котором по одному имени плагина в строке:

```
MySimplePlugin
Logger
```

В задании 7 программа **сама дописывает** строку `Greeter`, снова загружает плагины, а в конце **возвращает файл в исходное состояние** (две строки). Если запуск прервали посередине, удалите лишнюю строку `Greeter` вручную или выполните `dotnet build` заново.

## Что вы увидите (по блокам)

| Блок вывода | Что показывает |
|---|---|
| `ПРИМЕР: БАЗОВАЯ ИНСПЕКЦИЯ ТИПА` | сведения о классе `Product`: имя, пространство имён, конструкторы, методы, свойства, поля |
| `ПРИМЕР: РАБОТА С ПРИВАТНЫМИ ЧЛЕНАМИ` | чтение и изменение приватного поля, вызов приватного метода |
| `ПРИМЕР: ПОЗДНЕЕ СВЯЗЫВАНИЕ` | тип по имени-строке, создание объекта, вызовы методов |
| `ЗАДАНИЕ 1` | класс с валидацией свойств |
| `ЗАДАНИЕ 2` | список методов с флагами `BindingFlags` |
| `ЗАДАНИЕ 3` | создание объекта через `Activator.CreateInstance` |
| `ЗАДАНИЕ 4–6` | «чёрный ящик», изменение приватного поля, вызов приватного метода |
| `ЗАДАНИЕ 7` | загрузка плагинов по конфигурации |

## Где что лежит

| Файл | Содержимое |
|---|---|
| `Program.cs` | порядок запуска |
| `Examples.cs` | классы `Product` и `DynamicCalculator`, три примера методички |
| `Tasks.cs` | классы `ReflectionTarget`, `SecretCalculator`, задания 1–6 |
| `Plugins.cs` | интерфейс, атрибуты, плагины и загрузчик (задание 7) |
