# ССП-3. Теория кратко

- **Рефлексия** – получение информации о типах и работа с ними **во время выполнения**.
- **Классы:** `Type`, `FieldInfo`, `PropertyInfo`, `MethodInfo`, `ConstructorInfo`, `Assembly`, `Activator` (`System.Reflection`).
- **Получить `Type`:** `typeof(T)` (известен при компиляции), `obj.GetType()` (фактический тип объекта), `Type.GetType("имя")` (по строке).
- **BindingFlags:** `Public | NonPublic | Instance | Static`. Приватное поле: `NonPublic | Instance`.
- **Члены:** `GetField(...).GetValue/SetValue`, `GetMethod(...).Invoke(obj, args)`, `GetProperty`, `GetConstructor`.
- **Создать объект:** `Activator.CreateInstance(type [, args])` (без `new`).
- **Позднее связывание** – тип/метод выбираются по имени во время выполнения; **раннее** – при компиляции.
- **Атрибуты** – метаданные `[Plugin("x")]`; читаются `GetCustomAttribute<T>()`.
- **Плагины:** `IPlugin` + атрибут + `GetTypes()` + `IsAssignableFrom` + `Activator` + конфигурационный файл.
- **«Чёрный ящик»** – класс, структуру которого не знаем заранее.
- **Риски:** 1) нарушение инкапсуляции, 2) медленно, 3) ошибки при несоответствии структуры (только во время выполнения).
