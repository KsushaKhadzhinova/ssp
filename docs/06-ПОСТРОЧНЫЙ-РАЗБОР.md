# ССП, лабораторная работа 2. Построчный разбор кода

Здесь разобрана **каждая строка** каждого файла программы: номер строки, сама строка и что в ней происходит. Читайте файл рядом с исходным кодом: слева номер, в середине код, справа объяснение.


## Знаки, которые есть в каждой программе

| Знак | Что значит |
|---|---|
| `;` | конец команды (как точка в предложении) |
| `{ }` | границы блока: тела класса, метода, цикла, условия |
| `( )` | у метода – список аргументов; у `if`/`for`/`while` – условие; в выражении – порядок вычислений |
| `.` | «достать изнутри»: `Console.WriteLine` – метод `WriteLine` класса `Console` |
| `,` | разделитель аргументов, параметров, элементов списка |
| `=` | **присваивание**: правая часть вычисляется и записывается в левую (это не сравнение!) |
| `//` | комментарий до конца строки |
| `"…"` | строковый литерал (текст) |
| `[ ]` | индекс элемента массива (`a[0]` – первый) или признак массива в типе (`int[]`) |
| `< >` | у типа – параметры обобщения (`List<int>`); в выражении – «меньше/больше» |

В колонке «Разбор» сначала идёт смысл строки, а после `Слова и знаки:` – расшифровка каждого незнакомого слова и знака, которые в ней встретились. Пустые строки в таблице пропущены, номера строк совпадают с номерами в файле.
