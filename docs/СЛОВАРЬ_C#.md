# Словарь символов и слов C#

Если вы видите C# первый раз, начните здесь. В разборах кода каждое новое слово или знак объясняется при первом появлении, а общий список собран ниже.

## Знаки

| Знак | Название | Что значит | Пример |
|---|---|---|---|
| `;` | точка с запятой | конец команды (как точка в предложении) | `int a = 5;` |
| `{ }` | фигурные скобки | блок кода: тело метода, класса, цикла, условия | `{ sum += i; }` |
| `( )` | круглые скобки | вызов метода, параметры метода, условие в `if`/`for`, группировка в выражении | `Add(2, 3)` |
| `[ ]` | квадратные скобки | массив, индекс элемента, атрибут (в начале класса/метода) | `arr[0]`, `[Benchmark]` |
| `< >` | угловые скобки | **тип в обобщениях** (generics): `List<int>` – «список целых». В сравнениях – «меньше/больше» | `List<int>`, `a < b` |
| `=` | присваивание | положить значение в переменную (не «равно»!) | `x = 10;` |
| `==` / `!=` | сравнение | «равно» / «не равно», результат `true`/`false` | `if (x == 0)` |
| `+ - * / %` | арифметика | сложение, вычитание, умножение, деление, остаток | `a % 2` |
| `+=` `-=` `*=` | составное присваивание | `x += 5` то же, что `x = x + 5` | `sum += i;` |
| `++` `--` | инкремент / декремент | увеличить / уменьшить на 1 | `i++` |
| `&&` `\|\|` `!` | логика | «и», «или», «не» | `if (a > 0 && b > 0)` |
| `? :` | тернарный оператор | «условие ? если истина : если ложь» | `x < 0 ? 0 : x` |
| `??` | оператор объединения с null | «если слева null, то справа» | `name ?? "None"` |
| `?.` | безопасный доступ | вызвать, только если объект не `null` | `type.BaseType?.Name` |
| `.` | точка | «взять у объекта член»: поле, свойство, метод | `Console.WriteLine` |
| `,` | запятая | разделитель параметров и элементов | `Add(a, b)` |
| `=>` | лямбда / стрелка | «функция без имени» или короткая запись метода из одного выражения | `x => x + 1`, `int Sq(int a) => a * a;` |
| `//` | комментарий | текст для людей, компилятор игнорирует | `// это комментарий` |
| `/* */` | многострочный комментарий | то же на нескольких строках | |
| `"..."` | строка | текст | `"Привет"` |
| `$"...{x}..."` | интерполяция | строка, в которую подставляются значения в `{}` | `$"Сумма = {sum}"` |
| `\n` | перенос строки | внутри строки: новая строка | `"a\nb"` |
| `@"..."` | дословная строка | обратные слеши не нужно удваивать | `@"C:\work"` |
| `::` `:` | двоеточие | наследование/реализация интерфейса: `class A : B`; в `?:`; в `case` | `class A : IDisposable` |

## Слова (ключевые слова)

| Слово | Что значит |
|---|---|
| `using` | 1) подключить пространство имён (`using System;`) – «где искать классы»; 2) блок `using (...) { }` – автоматически освободить ресурс (вызвать `Dispose`) по окончании блока |
| `namespace` | «папка» для классов, чтобы имена не конфликтовали |
| `class` | класс – «чертёж» объектов: поля + методы |
| `static` | принадлежит классу, а не объекту; один на все объекты. `static void Main` вызывается без создания объекта |
| `public` / `private` / `protected` | доступ: всем / только внутри класса / внутри класса и наследников |
| `void` | метод ничего не возвращает |
| `int`, `double`, `bool`, `string`, `object`, `byte`, `long` | типы: целое, дробное, да/нет, текст, «любой объект», байт 0–255, длинное целое |
| `var` | «тип определит компилятор по правой части» |
| `new` | создать объект (`new List<int>()`) или массив (`new int[10]`) |
| `return` | вернуть результат метода и выйти |
| `if` / `else` | условие |
| `for` / `foreach` / `while` | циклы: со счётчиком / по элементам коллекции / пока условие истинно |
| `break` / `continue` | выйти из цикла / перейти к следующему шагу |
| `try` / `catch` / `finally` | обработка исключений (ошибок): пробуем / ловим ошибку / выполняется всегда |
| `throw` | выбросить исключение |
| `null` | «пустая ссылка» (объекта нет) |
| `this` | «текущий объект» |
| `const` / `readonly` | константа / поле, которое можно задать только в конструкторе |
| `get; set;` | свойство: читать и записывать значение |
| `event` | событие: «список подписчиков», которых уведомляют |
| `interface` | контракт: набор методов, которые обязан реализовать класс |
| `abstract` / `virtual` / `override` | абстрактный (без реализации) / можно переопределять / переопределяет |
| `is` / `as` | проверка типа / приведение типа |
| `Func<...>`, `Action<...>` | типы «ссылка на метод»: возвращает значение / не возвращает |
| `unsafe` | разрешает работу с указателями (нужен в проекте с `AllowUnsafeBlocks`) |

## Термины

- **Переменная** – именованная ячейка памяти: `int x = 5;` («тип имя = значение»).
- **Метод** – именованный кусок кода, который можно вызывать: `int Add(int a, int b) { return a + b; }`.
- **Параметр / аргумент** – данные, которые передают в метод.
- **Объект** – экземпляр класса, созданный через `new`.
- **Свойство** – «умное поле» с `get`/`set`.
- **Делегат** – объект, хранящий ссылку на метод; `Func<int,int,int>` – делегат с двумя `int` на входе и `int` на выходе.
- **Исключение** – ошибка времени выполнения (деление на ноль, файл не найден).
- **Атрибут** – метка-метаданные над классом/методом: `[Plugin("Calculator")]`.
- **Обобщение (generic)** – шаблон типа: `List<T>`; `T` – «любой тип, который подставят».
- **Рефлексия** – получение информации о типах во время работы программы.
- **IL** – промежуточный язык, в который компилируется C#.
- **JIT** – «на лету» компилятор IL в машинный код.
- **GC** – сборщик мусора.

## Как читать строку кода (пример)

```csharp
static int Multiply(int a, int b) => a * b;
```

1. `static` – метод принадлежит классу.
2. `int` (первый) – возвращает целое.
3. `Multiply` – имя метода.
4. `(int a, int b)` – два параметра-целых.
5. `=>` – «результат равен».
6. `a * b` – произведение.
7. `;` – конец.

```csharp
Console.WriteLine($"Сумма = {sum}");
```

1. `Console` – класс «консоль».
2. `.WriteLine` – метод «вывести строку и перейти на новую».
3. `$"..."` – строка с подстановкой.
4. `{sum}` – вместо этого знака подставится значение переменной `sum`.
